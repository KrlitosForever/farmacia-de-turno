# Guía de Contribución - Farmacia de Turno

¡Hola! Muchas gracias por tu interés en contribuir a **Farmacia de Turno**. Este proyecto busca ser una herramienta útil y accesible para consultar las farmacias disponibles, y la ayuda de la comunidad es fundamental para seguir mejorando.

Estás invitado a proponer mejoras, reportar errores o agregar nuevas características. Estaré muy feliz de analizar y conversar sobre cualquier propuesta que tengas.

## 💡 ¿Cómo puedes contribuir?

Puedes colaborar en el proyecto de muchas maneras:

*   **Reportando Bugs:** Si encuentras un error o algo que no funciona como debería, abre un *Issue* describiendo el problema, cómo reproducirlo y, si es posible, qué navegador o dispositivo estabas usando.
*   **Proponiendo Mejoras (Features):** Si tienes una idea para hacer la página más rápida, más bonita o más útil, abre un *Issue* con la etiqueta `enhancement` y cuéntame tu idea.
*   **Mejorando la Documentación:** Siempre se puede explicar mejor el código o el proceso de instalación.
*   **Enviando Pull Requests (PR):** Si ya tienes código listo para integrar, ¡envía tu PR!

## 🛠️ Pasos para enviar un Pull Request

Si deseas modificar el código y enviar tus cambios, por favor sigue estos pasos:

1.  **Haz un Fork del repositorio** haciendo clic en el botón "Fork" en la esquina superior derecha de esta página.
2.  **Clona tu fork** en tu máquina local:
```bash
    git clone https://github.com/TU_USUARIO/farmacia-de-turno.git
```
3.  **Crea una nueva rama (branch)** para tu funcionalidad o corrección. Usa un nombre descriptivo:
```bash
    git checkout -b feature/nueva-funcionalidad
    # o
    git checkout -b fix/correccion-error
```
4.  **Realiza tus cambios** en el código. Asegúrate de mantener un estilo de código limpio y ordenado.
5.  **Haz commit de tus cambios** con mensajes claros y descriptivos sobre lo que hiciste:
```bash
    git commit -m "Añade: filtro por comunas en la vista principal"
```
6.  **Sube los cambios (Push)** a tu repositorio remoto:
```bash
    git push origin feature/nueva-funcionalidad
```
7.  **Abre un Pull Request (PR)** en este repositorio original. En la descripción del PR, explica brevemente qué cambios realizaste y por qué. 

## 🤝 Proceso de Revisión

Revisaré tu *Pull Request* lo antes posible. Es posible que te deje algunos comentarios, sugerencias de cambio o preguntas sobre tu código. ¡No te preocupes, es parte normal del proceso de desarrollo colaborativo! La idea es que trabajemos juntos para integrar tu mejora de la mejor manera.

¡Gracias de nuevo por tu tiempo y por ayudar a mejorar este proyecto!
